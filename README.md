# APIGW PROXY TEMPLATE

This repository is used as a template for APIGW proxy repositories

Folder structure options and naming conventions for APIGW proxies

### A typical top-level directory layout

    .
    ├── .github                # Git workflow files
    ├── docs                   # Swagger specifications
    ├── scripts                # Script files to execute tests
    ├── src                    # Source files
    ├── tests                  # Automated tests - mock/functional/smoke
          ├── mock
    └── README.md

This proxy template repositories will be used by apigw-generic-workflow while creating/migrating repositories.
